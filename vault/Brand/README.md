# Brand

Shishka's identity, voice, visual system, and asset library. The brand is what a guest, a partner, or an investor sees and feels **before** they taste any dish. This folder is the index — the binaries (logos, photos, signboards) live on Google Drive at `01_Business/Branding/`, gitignored on purpose.

> [!info] One-line definition
> **Shishka Eat Healthy** — fresh as creation, alive like the soul. Healthy fast-food retail in Rawai, Phuket, with a fusion of Arab, Russian, International, and Thai cuisine. 20% healthier calories than competitors. Customizable salad bar, AI-driven nutrition, zero-waste kitchen.

## Naming conventions

- `Shishka-Kitchen-Logo-*` — current Dec 2025 master logo set
- `*-WG-*` — version on warm grey / dark background (white logo)
- `*-VIRTICAL-*` — vertical layout (typo preserved in original filenames)
- Date suffix `24-12-25` = 24 Dec 2025 (DD-MM-YY); update suffix when regenerating

## Rules

- **Read-only paths.** These are SSoT — never overwrite without CEO approval.
- **For new design work:** start from the `.ai` source, not the exported PNG. Preserves vector quality.
- **For docs / marketing:** prefer `Main Logo/Shishka-Kitchen-Logo-24-12-25.png` (main horizontal lockup).
- **For dark UIs:** use the `-WG-` variant (white text on warm grey/dark backgrounds).
- **Do not commit binaries from `01_Business/`** — that folder is gitignored on purpose; it is Drive content, not source.
