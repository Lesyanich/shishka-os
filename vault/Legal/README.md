# Legal

The corporate legal layer of Shishka — registration, work permits, visas, FDA licensing, restaurant permits, leases, tax filings, employment + supplier contracts, and any court papers. Custody is split across two surfaces: physical PDFs live on Google Drive under `00_Legal/`, the structured register lives in `docs/operations/company-documents-register.md`, and this page is the entity index that surfaces both on `/brain/drive`.

> [!info] One-line definition
> Legal is the document custody + compliance calendar layer — `/lawyer` agent classifies, files, and indexes every legal document, then emits MC tasks for upcoming deadlines (AGM, FS, WP renewal, VAT, PND, social security).

## Hard escalation triggers (Mr. Ram)

`/lawyer` is an advisor, not a licensed counsel. The following hit Mr. Ram immediately:

- Court papers (`10_Court_Papers/`) — any judicial filing
- Active litigation (lawsuit, summons, court hearing)
- Criminal matters (fraud, drugs, anything potentially criminal)
- Immigration appeals (visa denial, deportation, blacklist)
- Contracts > THB 500,000 (draft OK, signature requires review)

See [`agents/lawyer/AGENT.md`](../../agents/lawyer/AGENT.md) §Hard escalation for the full matrix.

## Maintenance protocol

Every time `/lawyer` files a new document:

1. Append row to `docs/operations/company-documents-register.md` with next `LEG-NNN` ID
2. Append matching `assets:` row to this file (`vault/Legal/README.md`) — so `/brain/drive` reflects it
3. If `expiry_date` set → emit T-60, T-30, T-7 MC tasks (`kind:legal-deadline`)
4. Respond in standard Bottom-line / Why / What I'd do / Mr. Ram trigger template

The vault-update step (item 2) is enforced — `BrainDriveMapPage` aggregates `assets:` frontmatter from this folder, so skipping it means the doc is invisible to CEO on `/brain/drive`.
