# Menu Categories

> **Pointer page.** The detail that used to live here was a 2026-04-29 snapshot that drifted out of date. Trust the source of truth below, not a copy. _(Wiki staleness audit, 2026-07-18.)_

**Source of truth:** the live menu — admin `/menu` route + `menu_public` DB view (categories are DB-driven, not maintained here).

- The `menu_public` view / `nomenclature` `SALE-%` rows are the only live list of what's on the menu and which category each dish sits in.
- ⚠️ The live menu is chocolate/drinks-led (🍫 ~25, ☕ ~19, plus juices/smoothies/matcha/thai-tea/lemonades); it has NO breakfasts and no 56-slot salad-bar model — those were an unshipped concept.
