## Naming conventions

- `Shishka-Kitchen-Logo-*` — current (Dec 2025) master logo set
- `*-WG-*` — version on warm grey / dark background (white logo)
- `*-VIRTICAL-*` — vertical layout (sic — typo preserved in original filenames)
- Date suffix `24-12-25` = 24 Dec 2025 (DD-MM-YY). Update suffix if regenerating.

## In-code copies (admin-panel)

The web app does not load from Google Drive — it bundles its own copy:

- `apps/admin-panel/src/assets/shishka-logo.png` — the only logo currently used in UI
- Imported via `import logo from '@/assets/shishka-logo.png'` pattern

If you change the master logo, manually copy the new PNG into
`apps/admin-panel/src/assets/` and commit. There is no automated sync.

## Notes for agents

- **Read-only:** these paths are SSoT, never overwrite without CEO approval.
- **For new design work:** start from the `.ai` source, not the exported `.png` — preserves vector quality.
- **For docs/marketing materials:** prefer `Main Logo/Shishka-Kitchen-Logo-24-12-25.png` (main horizontal lockup).
- **For dark UIs:** use the `-WG-` variant (white text on warm grey/dark backgrounds).
- **Do not commit binaries from `01_Business/`** — that folder is gitignored on purpose; it is Google Drive content, not source.

## How to access the binaries

`01_Business/Branding/` is a Google Drive shared folder. To read a binary:

1. **Local filesystem** — the path resolves on any machine that has the shared
   drive mounted (the agents/CEO laptops). Use `Read` tool with the full path.
2. **Google Drive MCP** — when local FS is not available, the
   `mcp__*__search_files` / `read_file_content` tools work directly against
   Drive. Search by filename, e.g. `Shishka-Kitchen-Logo-24-12-25`.
