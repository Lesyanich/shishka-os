## What The Full Audit Checks

### Phase 1: All active `data_health_rules`

Executes every `detect_sql` in the `data_health_rules` table.
Auto-applies WAC recalc for `zero_cost_with_purchases` (skips items with
`notes ILIKE '%free%'|'%in-house%'|'%recipe%'`).

**Known safe items excluded from zero-cost flag:**
- Tahini (notes: "free from friend's factory")
- Chili paste (notes: "in-house PF recipe")

### Phase 2: Smart duplicate detection

Runs three sub-checks:
1. **Name similarity >0.5 + same base_unit** → likely OCR duplicates
   (e.g., "AU Frozen Lamb Shoulder" vs "AU Frozen Lamb Leg" with same barcode 831436)
2. **1 barcode → multiple nomenclature items** → barcode collision
3. **RAW-AUTO / RAW-{hex8} still active** → unmerged auto-imports

### Phase 3: Makro barcode audit

Calls `tools/reconcile-unmatched/audit_makro_barcodes.py` against Makro Typesense API.
Compares every barcode we have to what Makro shows today.
Output: `tools/reconcile-unmatched/audit_report.csv`

Rate-limited to 2s per request. ~250 barcodes ≈ 8-10 minutes.

### Phase 4: Price drift + conversion sanity

- `cost_per_unit` vs `supplier_catalog.last_seen_price` drift >20%
- drift >1000% = broken `conversion_factor`
- `base_unit='g'` + `cost_per_unit<5` = likely should be `kg` (×1000 error)
- SALE dishes with no BOM lines
- SALE dishes with missing nutrition (calories/protein/carbs/fat)
- RAW items purchased in last 90 days but not in any BOM

### Phase 5: Report generation

Produces this file + commits it.

## Learned Patterns (Sheriff Encyclopedia)

These are confirmed real cases. The audit script detects all of them:

| Pattern | Detection | Example |
|---------|-----------|---------|
| OCR name variants = duplicates | name_sim >0.5 + same supplier | `เนื้อแกะ` → "Lamb Shoulder", "Lamb Leg", "Minced Lamb" (barcode 831436) |
| Unit confusion g vs kg | base_unit=g AND cost<5฿ | Gouda WAC=0.82/g → should be 822/kg |
| Broken conversion factor | cost vs last_seen_price drift >1000% | Olive Oil WAC=440/L but last_price=2200 (5L bottle) |
| Paste vs fresh misclassification | package context (can = paste, /kg = fresh) | "Fine Tomato Puree 400g" ≠ fresh tomato |
| Intentionally zero cost | notes ILIKE '%free%' | Tahini (friend's factory) — DO NOT FLAG |
| PF made in-house | notes ILIKE '%in-house%' | Chili paste — DO NOT FLAG as zero-cost |
| Weightless produce | no barcode on Makro receipt | Potatoes, onions, herbs — create most RAW-AUTO dups |
