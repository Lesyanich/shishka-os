Покажи **здоровье Shishka OS** — единый снимок состояния системы для CEO.

## Что делать

1. Запусти `bash scripts/health.sh` (находится в корне репо).
2. **Покажи stdout как есть** — он уже отформатирован для пользователя (русский, человекочитаемо, без технических ID).
3. Если скрипт вернул ненулевой код — покажи его stderr и предложи `bash scripts/health.sh --json` для отладки.

## Что включено в отчёт

- **Сейчас**: активная MC-задача (твоя сессия), фаза, ветка, последний коммит, dirty-файлы
- **Память**: счёт записей, последнее обновление, сколько старше 60 дней, статус
- **Качество данных**: ошибки/предупреждения/действия из `v_data_health`, score
- **Самообучение**: счётчики правил OCR, алиасов поставщиков, категорийных правок
- **Параллельные сессии**: другие in_progress задачи в MC, занятые другими сессиями

## Когда CEO просит подробности

Если CEO просит расшифровать какую-то секцию — НЕ запускай скрипт повторно, а:

- **Память**: открой директорию `~/.claude/projects/*hishka*/memory/` через `ls -lat | head` и покажи самые свежие/старые файлы
- **Параллельные сессии**: вызови `list_tasks(status="in_progress")` через MC MCP
- **Качество данных**: запроси `v_data_health_items` для конкретной метрики (нужен сервисный ключ)
- **Самообучение**: открой `correction_rules` / `supplier_aliases` через REST

## Что не делать

- Не предлагай «починить» что-либо автоматически — это команда наблюдения, не действия
- Не выводи технические ID, миграционные номера, имена файлов в основной выдаче
- Не дублируй вывод скрипта в своём ответе — просто прокинь его через

## Известные ограничения (v1)

- `health-score` из `v_data_health` иногда выходит за 0–100 (формула сломана). Скрипт это ловит и показывает «формула сломана, raw=…» — это нормальное поведение.
- «Старше 60 дней» считается по mtime файла, не по `last_verified` frontmatter. Точное определение появится после WS-2.
- Метрики авто/ручных корректировок появятся после WS-4 (показывается заглушка).

Спецификация: `scripts/health.sh` (header). MC: задача `0cc53ea6` (WS-5 of `75e735e5`).
