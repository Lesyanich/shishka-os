Покажи CEO, какие **скиллы / команды / MCP-инструменты** подходят под задачу. Это
браузер по реестру Skill Advisor — `docs/operations/skill-advisor.md`.

Запрос пользователя (может быть пустым): `$ARGUMENTS`

## Что делать

1. Прочитай реестр `docs/operations/skill-advisor.md` (секции по доменам + таблица `ADVISOR-MAP`).

2. **Если `$ARGUMENTS` непустой** — это описание задачи или ключевое слово:
   - подбери 1–4 наиболее релевантных инструмента (матчи по смыслу и по триггер-словам из `ADVISOR-MAP`);
   - для каждого дай: **как вызвать** (напр. `/finance`, `mcp shishka-chef`, `skill-creator`), **когда применять** (1 строка), и **что он делает лучше**, чем руками;
   - если задача про код — свериться с `docs/operations/skills-services-policy.md` § Task-Kind Taxonomy и упомянуть REQUIRED/**FORBIDDEN** скиллы для подходящего `kind:*`;
   - если ничего точно не подходит — честно скажи и предложи `find-skills` (поиск устанавливаемых скиллов).

3. **Если `$ARGUMENTS` пустой** — покажи компактную карту по доменам (Кухня, Финансы, Право,
   Закупки, Код, Дизайн, Данные, Браузер, Исследования, Документы, Задачи/GSD, Сессии,
   Расписание, Meta) — по 1 строке на инструмент: `вызов — когда`. Не вываливай весь файл.

## Формат ответа

- По-русски (разговор с CEO), кратко, сканируемо.
- Группируй по релевантности, самый подходящий — первым, с пометкой «рекомендую».
- В конце — одна строка: «Запустить?» с предложением самого подходящего варианта.

## Чего не делать

- Не запускай инструмент молча — это витрина выбора, решает CEO (RULE-SKILL-ADVISOR).
- Не дублируй полный текст реестра — только релевантную выжимку.
- Не выдумывай скиллы, которых нет в реестре или в списке доступных скиллов сессии.
