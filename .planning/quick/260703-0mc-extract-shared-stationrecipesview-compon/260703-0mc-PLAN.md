<objective>
Extract a shared, self-contained `<StationRecipesView>` component so the L1 Cook / L2 Assembler station experience is ONE component used in BOTH the owner `/menu` (`view=l1-cook|l2-assembler`) and the cook `/kitchen/recipes` routes.

Today the station filter wiring is duplicated in two places: MenuPage.tsx (two `<RecipeStationPanel>` blocks + their exclusive state) and KitchenRecipesPage.tsx (local-state filters). Every time a new control is added to one page (e.g. name-search, PR #469), the other page can silently miss it — a class of drift bug. StationRecipesView OWNS all station filter state via URL params (CEO decision) and exposes NO per-control props, so a parent can never again forget to wire a control.

Purpose: Kill the station-wiring drift bug permanently by collapsing two divergent wirings into one component.
Output: New `StationRecipesView.tsx` + its smoke test; MenuPage and KitchenRecipesPage rewired to delegate to it; dead exclusive state removed.
</objective>
