# Арифметическая верификация

**ОБЯЗАТЕЛЬНО перед сохранением payload проверь ВСЮ математику.**

## Чеклист

```
□ Проверка 1: Для КАЖДОЙ строки → qty × unit_price = total_price (±1 THB)
     Если не сходится → ПЕРЕЧИТАЙ эту строку чека

□ Проверка 2 (ANCHOR CHECK — самая важная):
     SUM(все total_price) ДОЛЖНА совпадать с НАПЕЧАТАННЫМ итогом на чеке
     ─────────────────────────────────────────────────────────────
     Найди на чеке строку "รวมทั้งหมด" / "Subtotal" / "Total before discount"
     Сравни: SUM(твои total_price) = напечатанный subtotal (±0 THB)
     ─────────────────────────────────────────────────────────────
     ⚠️  НЕ сравнивай сумму с СОБСТВЕННЫМ расчётом — привязывайся
         к ЦИФРЕ НА ФОТО. Иначе ошибка чтения строки пройдёт незамеченной.
     Если не сходится → см. "Протокол перечитывания" ниже

□ Проверка 3: subtotal + discount_total = amount после скидки
     discount_total ОБЯЗАТЕЛЬНО отрицательное (например, -134)

□ Проверка 4: amount_original = grand total с чека
     Итог в payload должен точно совпадать с TOTAL/ยอดรวมทั้งสิ้น на фото

□ Проверка 5: VAT = amount_original × 7 / 107 (для VAT-inclusive)
     Допустимое отклонение: ±1 THB
     Если на чеке напечатан VAT — используй напечатанное значение
```

## Протокол перечитывания (при расхождении)

### Шаг A: Определи размер ошибки
Посчитай `diff = SUM(твои items) - напечатанный subtotal`

### Шаг B: Сузь область поиска
- **Если diff — круглое число (10, 20, 40, 50, 100)** → скорее всего одна цифра прочитана неверно
- Раздели позиции пополам, пересчитай каждую половину — найди, в какой половине ошибка
- Повтори, пока не найдёшь конкретную строку

### Шаг C: Перечитай подозрительную строку
- Обрати внимание на цифры, которые легко спутать (см. таблицу ниже)
- Сверь unit_price × qty с напечатанным total_price в ПРАВОЙ колонке чека
- Если есть колонка "ส่วนลด" (скидка) — проверь, не пропущена ли построчная скидка

### Шаг D: Повтори Проверку 2
- НИКОГДА не сохраняй payload, пока SUM ≠ напечатанный subtotal

## Типичные ошибки чтения цифр

На тайских чеках (термопечать, сканы) часто путаются:

| Реальная | Прочитанная | Где чаще |
|----------|-------------|----------|
| **2** | **6** | Термопечать, мелкий шрифт |
| **6** | **8** | Размытые сканы |
| **1** | **7** | Наклонный шрифт |
| **5** | **8** | Потёртая бумага |
| **3** | **8** | Низкое разрешение |
| **0** | **6** / **8** | Размытость |

**Мнемоника**: если diff кратна 4 (40, 400) → ищи путаницу 2↔6.
Если diff кратна 3 (30, 300) → ищи путаницу 5↔8 или 0↔3.

## Если проверка не сходится после перечитывания

1. Проверь, не пропущена ли строка (особенно на стыке страниц)
2. Проверь, нет ли построчных скидок в колонке "ส่วนลด"
3. Проверь, не задвоена ли строка (одинаковый товар на разных страницах)
4. НИКОГДА не сохраняй payload с несходящейся арифметикой

## Формат отчёта

Включи в сводку:
```
Арифметика: {N} строк × верно | SUM = {X} vs printed {Y} ✓ | total {Z} - {D} disc + {V} vat = {G} ✓
```
